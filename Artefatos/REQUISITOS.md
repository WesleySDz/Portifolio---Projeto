# Requisitos do Sistema

## 1. Visão Geral

O sistema deve disponibilizar um portfólio digital que permita a diferentes perfis de interação explorar o conteúdo profissional, alternar entre perfis, navegar entre suas seções, contratar profissionalmente e inspecionar a arquitetura dos projetos apresentados.

## 2. Atores do Sistema

### 2.1 Visitante

Representa o indivíduo que acessa o sistema para explorar o portfólio com foco na identidade pessoal.

### 2.2 Empregador

Representa o indivíduo interessado em contratar profissionalmente por meio do sistema.

### 2.3 Desenvolvedor

Representa o indivíduo interessado em inspecionar a arquitetura dos projetos apresentados.

### 2.4 Usuário

Representa o ator associado às funcionalidades gerais de alternar perfil e navegar entre as seções do sistema.

## 3. Requisitos Funcionais

### RF-01 — Explorar Portfólio com Foco em Identidade Pessoal

O sistema deve permitir que o ator **Visitante** explore o portfólio com foco na identidade pessoal apresentada.

### RF-02 — Contratar Profissionalmente na Seção Contato

O sistema deve permitir que o ator **Empregador** utilize a seção contato com a finalidade de contratar profissionalmente.

### RF-03 — Alternar Perfil

O sistema deve permitir que o ator **Usuário** alterne entre perfis disponíveis no sistema.

### RF-04 — Navegar entre Seções

O sistema deve permitir que o ator **Usuário** navegue entre as seções do portfólio.

### RF-05 — Inspecionar Arquitetura dos Projetos

O sistema deve permitir que o ator **Desenvolvedor** inspecione a arquitetura dos projetos apresentados (seção projetos).
